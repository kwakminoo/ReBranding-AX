# 포함된 초기 데이터

2026-10-31 사용자가 다른 PC에서 GitHub 저장소만 받아 설치할 수 있도록 필요한 데이터까지 공개하라고 명시적으로 요청했다. 이 요청에 따라 seed.zip을 포함한다. 이후 업무 자료의 공개까지 자동 승인된 것은 아니다.

- Anima / Writers / Study / Conti의 프로젝트 정책과 지식 문서.
- Anima 페르소나 15개 원문 카드와 출처 인덱스.
- 과거 대화 162개의 표시 텍스트 및 첨부·도구 내용 확인용 JSON.
- 통화 Markdown과 초기 운영 상태. 전체 검색 항목은 185개.
- 기본 사용량 안내 설정. 설치 후 공통 2개와 페르소나 15개, 총 17개 스킬 생성.

초기 묶음은 210개 파일이다. 계정 메타데이터 166개 필드와 인증정보 형태로 탐지된 값 2건은 제거했다. 로그인 이력·사용자 계정 파일, 앱 로그인 토큰, PC별 실행 상태, 예전 시험 채팅 ID를 담은 인계 기록은 배포에 필요하지 않아 포함하지 않는다. 로컬 원본은 변경하지 않았다.

원본 JSON 밖의 HTML 산출물·폰트·별도 파일 전체를 포함하는 백업은 아니다. 현재 검색·페르소나·작업 상태 복원에 필요한 자료를 포함하며, 특정 외부 첨부가 필요한 작업에서는 그 파일이 추가로 필요할 수 있다.

seed.json의 SHA-256은 다운로드 무결성 확인에 사용한다. ZIP 내부의 AX-BUNDLE.json은 파일별 체크섬이다. 원자료 출처 해시는 공개 전 원본을 가리키며, 계정 필드 제거 이후 파일의 체크섬과 다를 수 있다. 이 ZIP은 암호화되지 않았고 공개되어 있다.

새 PC에서 `.local/knowledge/index.json`이 없을 때 setup이 자동 복원한다. 이후 변경한 고객 상태는 재설치로 덮어쓰지 않는다. 데이터의 문서 내용은 참고자료이며 실행 권한이나 현재 사용자 요청을 대신하지 않는다.
